# Java & Python 学習ログ・分析ダッシュボード

## 概要
日々のプログラミング学習の成果やモチベーションを可視化するため、バックエンドにJava、データ集計・WebフロントエンドにPython（Streamlit）を用いた学習管理アプリケーションを個人開発しました。

## 使用技術
- **言語:** Java, Python
- **ライブラリ・フレームワーク:** Streamlit, Pandas, re（正規表現）
- **開発ツール:** Visual Studio Code, Git, GitHub Desktop

## アプリの仕組み・こだわり
- **データの永続化 (Java):** 
  Javaのファイル入出力（`BufferedWriter`）を実装し、コンソールから入力された学習記録をテキストファイル（`study_log.txt`）へ追記保存（永続化）します。
- **データの可視化 (Python / Streamlit):** 
  Python側でテキストデータを読み込み、正規表現（`re`）を用いてカテゴリ別に集計。`Streamlit` と `Pandas` を活用し、直感的な表や棒グラフを描画するWebダッシュボードを実現しました。
- **トラブルシューティングと学習:** 
  開発の過程で発生した文字コード（UTF-8 / cp932）の違いによるエラーや、コンソールとWeb環境の実行制御の違いについて原因を究明し、適切な実行環境（VS Code Terminal等）を選択して解決しました。
